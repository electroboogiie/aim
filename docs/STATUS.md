# Стан розробки (пауза 19.10.2026)

Роботу поставлено на паузу на прохання користувача. Нижче — що готово і що лишилося.

## Готово і перевірено
- **Довідник** `catalog/catalog.json`: 21 позиція, 5 типів комплектів, 26 готових комплектацій з ваших КП, 20 аксесуарів, 7 цін «у комплекті». Джерела й відкриті питання: `catalog/README.md`, `docs/research/*.md`.
- **Ядро розрахунку** `core/`: формули з `docs/CONTRACTS.md` §4, 59 тестів проходять. 19 з 24 КП з надрукованою сумою відтворюються точно; 5 — ні, бо в КП кілька позицій надруковано одним рядком (перелік у звіті та `catalog/README.md`).
- **Генератор КП** `generator/`: дизайн KP_2_v3, профілі BMF 650/720/750, PDF через LibreOffice. 45 з 46 сторінок збігаються з еталоном піксель у піксель (різниця лише в мітці «ДІЙСНА ДО»).
- **Android** `android/`: обгортка WebView (Kotlin), збирається в GitHub Actions (`.github/workflows/android.yml`); локально не зібрано, бо немає Android SDK.
- **Розгортання**: `Dockerfile`, `docker-compose.yml`, `.env.example`, `docs/DEPLOY.md`, `docs/ANDROID.md`.

## Розпочато, не завершено
- **Сервер** `server/`: маршрути API, журнал (SQLite), черга генератора, курс НБУ. 97 з 98 тестів проходять; падає `server/test/rate.test.ts` («quotes use the reference rates»: очікується курс 48.10, отримано 49.5).
- **Web-версія** `web/`: конфігуратор, журнал, налаштування, демо-режим. Не перевірено в браузері.

2. Наскрізна перевірка: сервер + справжній генератор + web, усі комплекти з профілем.
3. Перевірка безпеки та правильності цін.
4. README, CLAUDE.md, перший запуск CI та збірки APK у GitHub Actions.
