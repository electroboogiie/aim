# Android-застосунок «Конструктор КП»

Застосунок — оболонка для веб-версії конструктора: усе, що є на сайті, працює і в ньому. Додатково він
запам’ятовує адресу сервера, оновлює сторінку жестом «потягнути вниз», має кнопку «Назад», завантажує КП
(PDF/PPTX) і одразу пропонує надіслати файл у Viber, Telegram чи поштою. Потрібен Android 7.0 або новіший.

## Де взяти APK

1. GitHub → репозиторій → вкладка **Actions** → workflow **Android**.
2. Відкрийте останній успішний (зелений) запуск → унизу, у розділі **Artifacts**, — `kp-android-debug-<номер>`
   (zip-архів, усередині `app-debug.apk`).
3. Передайте `app-debug.apk` на телефон (Telegram «Збережене», кабель, Google Диск).

APK збирається автоматично після кожної зміни в теці `android/`. Вручну: **Actions → Android → Run workflow**;
там же можна вказати адресу сервера, яку застосунок підставить сам (поле можна лишити порожнім).

## Встановлення

1. Відкрийте APK на телефоні. Android попросить дозволити встановлення з цього джерела (Файли, Telegram
   або браузер) — дозвольте.
2. Play Захист може попередити про невідомого розробника — натисніть «Усе одно встановити». Для
   внутрішнього застосунку поза Google Play це нормально.

## Перший запуск: адреса сервера

Під час першого запуску відкривається екран «Адреса сервера»:

- через інтернет — `https://kp.example.com` (лише https);
- в офісній мережі — `http://192.168.1.10:8080`, де 192.168.1.10 — IP комп’ютера чи сервера з конструктором.
  `http://` дозволено лише для адрес локальної мережі (192.168.x.x, 10.x.x.x, 172.16–31.x.x) і VPN Tailscale
  (100.64–127.x.x);
- `https://` можна не писати — застосунок додасть сам.

Натисніть «Перевірити з’єднання»: має з’явитися «З’єднання є. Версія сервера: …». Потім «Зберегти».

Змінити адресу пізніше: утримуйте значок застосунку → «Сервер», або на екрані помилки — «Налаштування».
Там же «Очистити дані сторінки» — якщо після оновлення сервера сторінка показує старе (видаляє кеш і вхід).

## Як користуватися

- Оновити сторінку — потягніть її вниз.
- КП: натисніть завантаження PDF або PPTX → «Поділитися» (Viber, Telegram, пошта…), «Відкрити» або
  «Зберегти копію» (у «Завантаження» чи іншу теку).
- Немає інтернету — з’явиться «Немає з’єднання з мережею»; сторінка відкриється сама, щойно повернеться
  зв’язок (або натисніть «Повторити»).
- Офлайн-режим веб-версії працює лише через https.

## Оновлення застосунку

Новий APK встановлюється поверх старого, лише якщо обидва підписані тим самим ключем. Поки ключ не
налаштовано, кожна збірка на GitHub підписана новим тимчасовим ключем: старий застосунок доведеться видалити
й заново ввести адресу сервера.

Постійний ключ (робить один раз адміністратор репозиторію; потрібна Java з `keytool`):

```sh
keytool -genkeypair -v -keystore debug.keystore -storepass android -alias androiddebugkey \
  -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
base64 -w0 debug.keystore        # macOS: base64 -i debug.keystore
```

Скопіюйте виведений текст у GitHub: **Settings → Secrets and variables → Actions → New repository secret**,
назва `ANDROID_DEBUG_KEYSTORE_B64`. Файл `debug.keystore` збережіть у надійному місці й не додавайте в git.

## Збірка на своєму комп’ютері (необов’язково)

Потрібні JDK 17, Android SDK (Android Studio або command-line tools) і Gradle 8.14:

```sh
gradle -p android assembleDebug                                         # android/app/build/outputs/apk/debug/app-debug.apk
gradle -p android assembleDebug -Pkp.serverUrl=https://kp.example.com   # з адресою сервера за замовчуванням
```

Або відкрийте теку `android/` в Android Studio.

## Якщо щось не так

| Повідомлення | Що робити |
|---|---|
| «Сервер недоступний» | Перевірте адресу і чи запущено сервер. У локальній мережі: телефон у тому ж Wi‑Fi, порт 8080 відкрито в брандмауері Windows (docs/DEPLOY.md). |
| «Помилка захищеного з’єднання» | Сертифікат https недійсний або на телефоні неправильні дата й час. Самопідписані сертифікати не підтримуються — використовуйте Let’s Encrypt (docs/DEPLOY.md). |
| «Адреса http:// дозволена лише в локальній мережі» | Для доступу через інтернет потрібна адреса https://. |
| «Немає доступу до файлу (код 401)» | Оновіть сторінку й увійдіть ще раз (токен доступу). |

Для розробників веб-версії: як сторінка може передати файл застосунку — `docs/CONTRACTS.md`, §8.
