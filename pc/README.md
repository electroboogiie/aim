# Конфігуратор КП — тестова модель для ПК

Локальна програма: працює на вашому комп’ютері, відкривається в браузері (http://127.0.0.1:8765), інтернет не потрібен.
Створює КП у PPTX і PDF тим самим генератором, що й набір КП `kp_set_v4`.

## Запуск на Windows

1. Один раз встановіть **Python 3.11+** (python.org, позначте «Add python.exe to PATH») і **LibreOffice** (libreoffice.org, потрібен для PDF).
2. Розпакуйте архів у будь-яку теку і двічі клацніть `pc\start.bat`.
   Перший запуск сам встановить бібліотеки (python-pptx, Pillow, numpy) — потрібен інтернет лише цього разу.
3. Браузер відкриється сам. Закрити програму — закрити чорне вікно.

## Що є

**Конфігуратор**: тип комплекту → готова комплектація з ваших КП або вибір позицій → опції → ціни (з адмінки,
можна вписати фінальну ціну для цієї КП, знижку) → номер, замовник, стиль → «Створити КП». Файли: вкладка «Історія».

**Адмінка** (усе зберігається одразу, `pc/data/admin.json`):
- **Стиль** за замовчуванням: темний KP_2_v3, його світла тема, світлий з помаранчевою панеллю, НПЛ-10 «Heavy Label» (лише НПЛ-10 + кран).
- **Підкладки сторінок** для кожного стилю: своє фото на будь-яку сторінку. Обкладинка, кран, причіп, контакти — фото
  обробляється під стиль (з точкою фокусу); інші сторінки — фото накладається на фон стилю з прозорістю, яку ви задаєте.
- **Тексти сторінок**: постійні тексти шаблону кожного стилю (заголовки, підписи, переваги), умови співпраці, описи кранів і НПЛ-10.
- **Фото позицій і опцій**: фото плитки на сторінці «Конфігурація» і карток «Додаткові опції».
- **Ціни**: базова ціна × (1 + націнка %) = розрахункова; фінальна ціна (якщо вписана) її замінює; видно додану вартість.
  Націнку можна задати всій групі. Типово базова ціна = ціна з останньої КП, націнка 0 %.

## Обмеження тестової моделі
- Стиль «НПЛ-10 Heavy Label» має 4 рядки у вартості й фото крана BMF 720 на сторінках крана (для 650/750 змінюються лише цифри й тексти).
- Ціни прив’язані до гривні; курс EUR і метал у цій моделі не перераховуються.
- Без входу за паролем: програма доступна лише на цьому комп’ютері.

## Для розробника
Розрахунок цін — ядро `core/` (TypeScript), зібране для браузера в `pc/static/core/`:
`tsc -p pc/tsconfig.core-web.json`. Сервер — `pc/server.py` (лише стандартна бібліотека Python), генератор — `generator/kpgen`
(`spec.style`, `spec.overrides.bg/texts`, `rows[].photo_force`). Шаблони стилів: `generator/templates/`, оновлення з файлів
дизайну — `generator/tools/make_style_templates.py`.
